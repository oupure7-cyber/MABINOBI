## 1. AI 커넥터란

- **PC 버전** 마비노기 모바일에서, PC에 설치된 **AI 도구**를 실행해 채팅·채집·제작·가공 같은 게임의 일부 동작을 **대신 수행하도록 요청**할 수 있는 공식 기능.
- 게임 화면을 직접 조작하지 않고, AI에게 대화하듯 요청하면 AI 도구가 필요한 정보를 묻거나 활동을 대신 수행.

### 사용 방법
- `[메뉴(≡)] → [환경설정] → [게임] → [AI 제어]` 에서 AI 커넥터 옵션을 켠다.
- 옵션을 켜면 이용 확인 팝업 표시 → 안내 내용 확인 및 체크 → **[활성화]** 클릭해야 최종 적용.
- **PC 버전에서만 동작**, 사용자의 'AI 도구'가 PC에 설치되어 있어야 함.
- 기본값은 **꺼짐**이며, 직접 켜지 않는 한 어떠한 동작도 하지 않음.
- ⚠️ 활성화 후 **7일간 미사용 시 옵션 자동 꺼짐**.

## 2. 사용 가능한 AI 도구

마비노기 모바일이 AI를 직접 제공하는 것이 아니라, **사용자가 쓰던 AI 도구와 게임 연결**이 필요함.

| 사용 가능한 AI 도구 |
|---|
| Claude Code |
| Cursor |
| Gemini CLI / Antigravity |
| Windsurf |
| Cline / Roo Code |
| Kiro |
| OpenCode |

- PC에 위 AI 도구가 설치되어 있으면 AI 커넥터가 **자동으로 인식**.
- AI 커넥터는 **AI 도구 ↔ 게임 클라이언트 연결 역할만** 수행. AI 도구 실행·로그인은 각 AI 도구 프로그램에서 별도로 진행.
- AI 커넥터를 통한 요청은 **사용자 본인의 AI 도구 계정(개인 토큰/구독)**으로 처리되며, AI 도구 사용량에 따라 **별도 이용 요금이 부과될 수 있음**.
  - 이 비용은 AI 도구 제공사에 지불하는 비용으로, **마비노기 모바일이 부담/제공하지 않음**. 게임 내 '정령의 날개' 소비와는 별개.
- 지원 도구 목록은 업데이트에 따라 추가/변경될 수 있음.

## 3. 활용 범위 및 방법

AI 도구에게 원하는 행동을 대화하듯 요청하면, AI 커넥터가 아래 동작을 대신 수행.

| 분류 | 예시 |
|---|---|
| 채팅 | 채팅 메시지 전송 |
| 퀘스트 / 미션 | 진행 중인 퀘스트, 일일/주간 미션 목록과 진행도 확인 |
| 내 정보 조회 | 캐릭터 능력치, 소지 재화, 인벤토리 무게 확인 |
| 채집 | 지정한 재료를 목표 수량까지 채집, 낚시터에서 자동 낚시 시작 |
| 제작 / 가공 | 지정한 아이템 제작, 가공 작업 등록과 결과 수령 |
| 연주 | 보유한 악기로 지정한 악보 연주 |
| 주변 정보 조회 | 근처 NPC, 플레이어, 현재 위치와 날씨 확인 |

- 다른 모험가의 정보(캐릭터 이름, 길드명, 다른 모험가와 주고받은 채팅 내용 등)는 전달되지 않음.

### ❌ 활용 불가 범위 (예시)
- 거래소 등록 및 구매
- **성장과 관련된 자동 플레이**
- 결제 및 캐시샵 이용
- 길드 운영(추방, 임명 등)
- 1:1 대화 전송
- 아이템 버리기 및 분해
- 외부 메신저 / SNS 연동

> 실제 활용 범위는 업데이트에 따라 추가/변경될 수 있음.

## 4. 최초 연결 시 사용법

AI 커넥터는 정해진 명령어가 아니라 **대화체로 사용** 가능.

### 1) 최초 연결 확인
| 화자 | 내용 |
|---|---|
| 모험가님 | "마비노기 모바일 지금 켜져 있고 AI 커넥터 연결되는지 확인해줘" |
| AI 도구 답변 | "확인했어요. 게임이 켜져 있고 AI 커넥터도 정상 연결되어 있어요. 어떤 걸 도와드릴까요?" |

### 2) 원하는 행동 요청 (예시)
- "철광석 20개 채집해줘"
- "오늘 일일 미션 뭐 남았는지 알려줘"
- "악기로 '바람의 노래' 연주해줘"

## 5. 채팅 사용 방법

- AI 커넥터는 일반 채팅을 작성할 수 있으나, **모험가님의 확인 없이는 절대 전송되지 않음**.
- 전송하려는 내용을 먼저 사용자에게 보여주고, **승인한 경우에만 전송**.
- 채팅 도배 행위나 타인에게 불쾌감을 주는 메시지가 탐지되면 운영정책에 따라 채팅 제한 가능.
- AI 도구로 작성된 채팅에는 캐릭터 이름 옆에 **AI 아이콘** 표시됨 (참고 이미지: `assets/ai_icon.png`).

---

## 6. 활용 시 유의사항

- AI 커넥터를 통해 활동을 진행할 경우, **활동 1회당 '정령의 날개' 5개 소모**.
- 정령의 날개가 소비되는 동작 시 AI 도구가 정말 사용할지 재확인할 수 있음.
- 정령의 날개가 부족하면 해당 활동은 실행되지 않음 (일일 미션 등으로 획득 가능).
- **정보 조회(물어보기)는 정령의 날개를 소모하지 않음** (능력치, 재화, 인벤토리, 퀘스트 진행 등).
- AI 커넥터가 **1시간 동안 계속 실행되면 안전 확인 팝업** 표시 → 확인 시 계속 진행 가능.
- AI 커넥터 사용으로 발생하는 모든 결과(비용 포함)는 **사용자 본인에게 귀속**.
- 운영정책 위반 행위가 확인되면 **이용 제재** 가능.
- 각 AI 도구 자체의 오류는 해당 AI 도구 제공사에 문의.

## 7. (참고) 윈도우 PC에 Gemini CLI 설치하는 방법

AI 도구가 없는 경우를 위한 넥슨의 참고 안내.

**Gemini CLI란**: 웹사이트형 Gemini 대신, 터미널에서 Gemini AI를 불러와 파일 작업/코드 분석/문서 작성 등을 도와주는 도구.

### 설치 단계
1. **Node.js 설치**: `nodejs.org` 접속 → `Get Node.js` 버튼 클릭 → `.msi` 실행 → Next 반복, 약관 동의 → Install → Finish.
2. **명령 프롬프트(CMD) 열기**: `Win` 키 또는 검색창 → `cmd` 입력 → 명령 프롬프트 실행.
3. **설치 명령어 입력**:
   ```
   npm install -g @google/gemini-cli
   ```
4. **실행 및 로그인**:
   ```
   gemini
   ```
   - 최초 실행 시 인증 방식 선택 화면 → 방향키로 `Sign in with Google` 선택 → Enter
   - 브라우저에서 구글 계정 로그인 및 권한 승인
   - "Success" 확인 후 명령 프롬프트로 복귀

- 추가 참고: [Gemini CLI 설치 가이드](https://geminicli.com/docs/get-started/installation/)

### 기본 사용법
- 명령 프롬프트에서 `gemini` 입력 후 실행, 한국어로 자유롭게 질문/요청.
  - 예: "마비노기 모바일 지금 켜져 있고 AI 커넥터 연결되는지 확인해줘"

### 자주 발생하는 오류

| 증상 / 오류 메시지 | 원인 및 해결 방법 |
|---|---|
| `'npm'은(는) 내부 또는 외부 명령...이 아닙니다.` | Node.js가 정상 설치되지 않았거나, 설치 후 명령 프롬프트를 재시작하지 않은 경우. 창을 닫고 다시 열기. |
| 권한 오류 (EACCES / EPERM) | 명령 프롬프트를 마우스 우클릭 → **관리자 권한으로 실행**하여 재시도. |
| `gemini` 실행 불가 | Node.js 설치 후 **컴퓨터 재부팅** 후 재시도. |

- 위 방법으로도 해결이 안 되면 [구글 고객센터](https://support.google.com/?hl=ko) 문의.

## 요약: 자동화 설계 시 지켜야 할 경계선

앞으로 이 가이드를 기반으로 제어 프로그램을 설계할 때 반드시 지켜야 할 공식 제약:

1. **허용된 범주 내에서만** 동작 (채팅[승인 필요]/퀘스트·미션 조회/내정보 조회/채집·낚시/제작·가공/연주/주변 정보 조회).
2. **거래소, 캐시샵/결제, 길드 운영, 1:1 메시지, 아이템 버리기/분해, 외부 메신저 연동, "성장과 관련된 자동 플레이"는 명시적으로 금지 범위** — 이 영역은 자동화 대상에서 제외해야 함.
3. 채팅 전송은 **사용자 승인 없이 자동 전송 금지** (공식 정책상 항상 승인 단계가 있어야 함).
4. **정령의 날개** 재화 소모(활동 1회당 5개)와 **1시간 연속 실행 시 확인 팝업**은 공식 제공 세이프가드이므로, 이를 우회하거나 무력화하는 방향의 자동화는 설계하지 않음.
5. 반복적 채팅(도배)이나 불쾌 메시지 자동 생성은 제재 대상이므로 자동화 로직에 포함하지 않음.
