# 요구사항

## 기능 요구사항

### 자동화 대상 동작 (범위는 [02_scope_boundaries.md](02_scope_boundaries.md) 준수)

| ID | 동작 | 입력 | 트리거 방식(안) |
|---|---|---|---|
| F1 | 채집 | 재료명, 목표 수량 | 스케줄 (예: 매일 특정 시각) 또는 조건 (예: 인벤토리 여유 있을 때) |
| F2 | 자동 낚시 | 낚시터 지정 여부 | 스케줄 |
| F3 | 제작/가공 등록 및 결과 수령 | 아이템명, 수량 | 스케줄 또는 재료 확보 시 |
| F4 | 연주 | 악보명 | 스케줄 또는 수동 트리거 |
| F5 | 퀘스트/미션 진행도 조회 | 없음 | 주기적 조회 (정령의 날개 미소모이므로 자유롭게 사용 가능) |
| F6 | 내 정보 조회 (재화/인벤토리 무게 등) | 없음 | 주기적 조회, 다른 동작의 사전 조건 확인용으로도 사용 |
| F7 | 채팅 메시지 초안 생성 | 상황/템플릿 | 항상 사용자 승인 단계 거침 (자동 전송 없음) |

### 스케줄/조건 관리
- 사용자가 각 동작(F1~F4)에 대해 스케줄(시간 기반) 또는 조건(재화/인벤토리 상태 기반)을 설정할 수 있어야 한다.
- 실행 전 F6(내 정보 조회)으로 사전 조건(인벤토리 여유, 정령의 날개 잔량 등)을 확인하는 흐름을 지원해야 한다.

### 로깅 및 감사
- 모든 자동 요청은 요청 시각, 요청 내용, 예상/실제 정령의 날개 소모량, 결과(성공/실패/사용자 대기)를 기록한다.
- 로그는 사용자가 나중에 검토할 수 있는 형태(파일 등)로 남는다.

### 제어
- 사용자가 언제든 전체 자동화를 즉시 정지할 수 있어야 한다.
- 개별 동작(F1~F4) 단위로도 켜고 끌 수 있어야 한다.

## 비기능 요구사항

- **세이프가드 존중**: 1시간 연속 실행 확인 팝업, 채팅 전송 승인 팝업 등 공식 UI 상호작용을 프로그램이 대신 처리(자동 클릭)하지 않는다. 팝업이 뜨면 대기 상태로 전환하고 사용자에게 알린다.
- **정령의 날개 예산 관리**: 하루 자동 소모량에 대한 상한을 사용자가 설정할 수 있어야 한다 (초과 시 해당 동작 자동 중단).
- **오류 처리**: AI 도구/게임 연결이 끊기거나 요청이 실패하면 재시도 대신 로그를 남기고 다음 스케줄까지 대기한다 (무한 재시도로 인한 도배/제재 위험 방지).
- **관찰 가능성**: 현재 자동화 상태(켜짐/꺼짐, 마지막 실행 시각, 마지막 결과)를 언제든 확인할 수 있어야 한다.
