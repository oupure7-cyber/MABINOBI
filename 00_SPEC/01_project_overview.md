# 프로젝트 개요

## 배경

넥슨 마비노기 모바일이 PC 버전에서 공식 **AI 커넥터** 기능을 제공한다. 이 기능은 사용자가 설치한 AI 도구(Claude Code, Cursor, Gemini CLI 등)와 게임 클라이언트를 연결해, 대화형 요청으로 채팅·채집·제작·가공 등 일부 게임 동작을 대신 수행하게 해준다. 자세한 공식 사용법은 [81_GUIDE_MD](../81_GUIDE_MD/마비노기_모바일_AI_커넥터_가이드.md) 참고.

## 목표

마비노기 모바일 AI 커넥터를 통해, **사용자가 매번 대화로 요청하지 않아도** 지정한 조건/스케줄에 따라 허용된 게임 동작(채집, 제작·가공, 낚시, 퀘스트/미션 확인, 정보 조회 등)이 자동으로 트리거되는 제어 프로그램을 만든다.

## 비목표 (Non-goals)

- [00_SPEC/02_scope_boundaries.md](02_scope_boundaries.md)에 명시된 금지 범위(거래소, 캐시샵/결제, 길드 운영, 1:1 메시지, 아이템 버리기/분해, 외부 메신저 연동, "성장과 관련된 자동 플레이")는 다루지 않는다.
- 공식 세이프가드(정령의 날개 소모량 제한, 1시간 연속 실행 확인 팝업, 채팅 전송 전 사용자 승인)를 우회하거나 무력화하는 기능은 만들지 않는다.
- 다른 플레이어 계정을 대상으로 하거나, 여러 계정을 동시에 자동화하는 것은 다루지 않는다 (본인 계정 1개 기준).

## 성공 기준

- 지정한 스케줄/조건(예: "매일 오전 9시에 특정 재료 20개 채집 요청")에 따라 AI 커넥터에게 자동으로 요청이 전달된다.
- 정령의 날개 소비, 1시간 팝업, 채팅 승인 등 공식 세이프가드가 그대로 유지된다 (제어 프로그램이 이를 대신 눌러주거나 우회하지 않는다).
- 모든 자동 요청과 결과가 로그로 남아, 사용자가 나중에 무엇이 실행됐는지 확인할 수 있다.
- 금지 범위에 해당하는 요청은 프로그램 차원에서 생성되지 않는다 (요청 생성 단계에서 필터링).

## 전제 조건

- PC 버전 마비노기 모바일 + AI 커넥터 옵션 활성화
- 지원 AI 도구(현재 Claude Code 포함) 설치 및 로그인
- AI 커넥터가 실제로 어떤 인터페이스를 노출하는지는 아직 미확인 → [10_RESEARCH](../10_RESEARCH/01_ai_connector_interface.md)에서 조사 예정
