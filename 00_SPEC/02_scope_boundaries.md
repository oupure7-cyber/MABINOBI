# 허용/금지 범위 계약

> 이 문서는 [81_GUIDE_MD](../81_GUIDE_MD/마비노기_모바일_AI_커넥터_가이드.md)에 정리된 넥슨 공식 정책을 이 프로젝트의 개발 계약으로 재정리한 것이다. 공식 정책이 업데이트되면 81_GUIDE_MD를 먼저 갱신하고, 이 문서를 그에 맞춰 다시 검토한다.

## 허용되는 자동화 대상

| 분류 | 자동화 가능 여부 | 비고 |
|---|---|---|
| 채집 (지정 재료 목표 수량까지) | ✅ | 정령의 날개 소모 |
| 자동 낚시 시작 | ✅ | 정령의 날개 소모 |
| 제작 / 가공 등록 및 결과 수령 | ✅ | 정령의 날개 소모 |
| 연주 (보유 악기로 지정 악보) | ✅ | 정령의 날개 소모 |
| 퀘스트/미션 목록·진행도 조회 | ✅ | 정령의 날개 미소모 |
| 내 정보 조회 (능력치/재화/인벤토리) | ✅ | 정령의 날개 미소모 |
| 주변 정보 조회 (NPC/플레이어/위치/날씨) | ✅ | 정령의 날개 미소모 |
| 채팅 메시지 전송 | ⚠️ 제한적 허용 | **사용자 승인 없이 자동 전송 절대 금지** |

## 금지되는 범위 (자동화 대상에서 제외)

- 거래소 등록 및 구매
- **성장과 관련된 자동 플레이** (레벨업/전투 자동화 등으로 해석 — 애매하면 만들지 않는다)
- 결제 및 캐시샵 이용
- 길드 운영 (추방, 임명 등)
- 1:1 대화 전송
- 아이템 버리기 및 분해
- 외부 메신저/SNS 연동

## 이 프로젝트가 추가로 지키는 자체 안전장치

1. **채팅 자동 전송 금지**: 어떤 트리거 조건이든, 채팅 메시지는 항상 사용자 확인 단계를 거친다. 프로그램이 승인 팝업을 대신 클릭하지 않는다.
2. **정령의 날개 예산 인지**: 자동 요청을 대량으로 큐에 쌓아 하루 한도를 소진시키는 방식은 지양한다. 요청 전 예상 소모량을 로그에 남긴다.
3. **1시간 연속 실행 팝업 존중**: 이 팝업이 뜨면 프로그램은 자동으로 클릭하지 않고 사용자에게 알리고 대기한다.
4. **로깅**: 모든 자동 요청(시각, 요청 내용, 결과)을 기록한다.
5. **강제 종료 스위치**: 언제든 즉시 자동화를 멈출 수 있는 명확한 방법을 제공한다 (구체 설계는 [20_DESIGN](../20_DESIGN/01_architecture.md)에서 정의).
6. **범위 필터**: 요청을 생성하는 단계에서 위 "금지되는 범위"에 해당하는 요청은 아예 만들어지지 않도록 화이트리스트 방식으로 제한한다 (금지 키워드 블랙리스트가 아니라, 허용 목록에 있는 것만 실행).

## 애매한 경우 처리 원칙

- 공식 문서에 명시되지 않았거나 허용/금지가 불분명한 동작은 **기본적으로 자동화하지 않는다**. 필요하면 [10_RESEARCH](../10_RESEARCH/01_ai_connector_interface.md)에 질문으로 남기고, 실제 확인 후 이 문서를 갱신한다.
