# 사용자 설치 가이드 (배포용)

> 이 문서는 이 프로젝트(제어 프로그램)를 **다른 유저에게 배포**할 때, 유저가 처음 시작할 때 거쳐야 하는 사전 준비 과정을 정리한 문서다. 개발 중 실제로 거친 설치 과정을 기준으로 작성했다.
>
> 넥슨 공식 AI 커넥터 자체에 대한 설명은 [81_GUIDE_MD/마비노기_모바일_AI_커넥터_가이드.md](../81_GUIDE_MD/마비노기_모바일_AI_커넥터_가이드.md) 참고. 이 문서는 그 전 단계, 즉 **"AI 도구를 아예 처음 쓰는 유저"** 가 AI 커넥터를 쓸 수 있는 상태까지 준비시키는 것을 목표로 한다.

> 이 문서의 메인 흐름은 **Claude Code** 기준이다. **Codex(OpenAI)**를 쓰고 싶다면 1단계와 5단계 대신 [7단계: Codex 사용자용 설정](#7단계-codex-사용자용-설정-claude-code-대신)을 따를 것.

## 1단계: Claude Code 설치

Claude Code는 터미널에서 Claude AI를 불러와 파일 작업, 코드 실행, 이 프로젝트의 MCP 서버 연결 등을 수행하는 CLI 도구다.

1. **Node.js 설치 확인**: Claude Code는 Node.js가 필요하다.
   - `node --version` 을 명령 프롬프트(CMD)나 PowerShell에서 입력해 설치 여부 확인.
   - 없다면 [nodejs.org](https://nodejs.org)에서 `.msi` 다운로드 후 설치 (Next 반복 → 설치 → 재부팅 또는 터미널 재시작).
2. **Claude Code 설치**:
   ```
   npm install -g @anthropic-ai/claude-code
   ```
3. **설치 확인**:
   ```
   claude --version
   ```

> 참고 (다른 AI 도구를 쓰고 싶은 경우): 넥슨 공식 가이드는 Cursor / Gemini CLI / Windsurf / Cline·Roo Code / Kiro / OpenCode도 지원한다고 안내한다. Gemini CLI 설치 방법은 [81_GUIDE_MD 7절](../81_GUIDE_MD/마비노기_모바일_AI_커넥터_가이드.md#7-참고-윈도우-pc에-gemini-cli-설치하는-방법) 참고. 이 프로젝트는 Claude Code 기준으로 작성됐다.

## 2단계: Claude 계정 생성 / 로그인

1. 터미널에서 `claude` 입력해 최초 실행.
2. 로그인 방식 선택 화면이 뜨면 **Claude 계정으로 로그인**(브라우저 인증) 선택.
3. 이미 [claude.ai](https://claude.ai) 계정이 있으면 그대로 로그인.
4. 계정이 없으면 브라우저에서 계정 생성(이메일 또는 구글 계정) 후 인증 완료 → 터미널로 자동 복귀.

---

## 3단계: 구독(또는 사용량 결제) 연결

Claude Code는 **개인 계정의 구독/사용량**으로 동작한다. 무료 계정은 메시지·사용량 제한이 있어, 반복적으로 게임 자동화 요청을 보내려면 아래 중 하나가 필요하다.

- **Claude Pro/Max 구독** (권장, 일반 사용자 대상): [claude.ai/upgrade](https://claude.ai/upgrade)에서 결제 수단 등록 후 구독.
- **Anthropic API 종량 결제** (개발자/고급 사용자 대상): [console.anthropic.com](https://console.anthropic.com)에서 조직 생성 → 결제 수단 등록 → API 크레딧 충전. 이 경우 `claude` 로그인 시 "Anthropic API 사용" 방식을 선택.

> ⚠️ 이 비용은 마비노기 모바일과 무관하게 **Anthropic에 지불하는 비용**이다 (81_GUIDE_MD 2절 참고). 정령의 날개 소비와는 완전히 별개다.

구독/결제가 연결되지 않은 상태로는 반복 요청 시 사용량 제한에 걸릴 수 있으니, 배포 시 이 단계를 건너뛰지 않도록 안내가 필요하다.

## 4단계: Python 설치 (MCP 서버 구동용)

이 프로젝트의 MCP 서버(`30_MCP_SERVER/server.py`)는 Python으로 작성되어 있어 별도로 Python이 필요하다.

1. **winget으로 설치** (Windows 10/11):
   ```
   winget install Python.Python.3.12
   ```
   또는 [python.org](https://www.python.org/downloads/)에서 설치 파일 다운로드 후 설치 (설치 시 **"Add python.exe to PATH"** 체크 필수).
2. **설치 확인** (새 터미널 창에서):
   ```
   python --version
   ```
3. **MCP 서버 의존성 설치**:
   ```
   pip install -r 30_MCP_SERVER/requirements.txt
   ```

## 5단계: 이 프로젝트(MCP 서버) 연결

1. 이 프로젝트 폴더를 다운로드/클론.
2. 해당 폴더에서 `claude` 실행 (또는 Claude Code에서 폴더 열기).
3. 프로젝트 루트의 `.mcp.json`에 `mabinogi-ai-connector` 서버가 등록되어 있어 **자동으로 인식**된다.
4. 최초 1회, MCP 서버 사용 승인 프롬프트가 뜨면 **허용**.
5. 정상 연결되면 Claude에게 "내 캐릭터 정보 조회해줘" 같은 요청으로 동작 확인 가능.

자세한 서버 구성은 [30_MCP_SERVER/README.md](../30_MCP_SERVER/README.md) 참고.

## 6단계: 마비노기 모바일 AI 커넥터 옵션 켜기

1. 마비노기 모바일 **PC 버전** 실행.
2. `[메뉴(≡)] → [환경설정] → [게임] → [AI 제어]`에서 AI 커넥터 옵션 켜기.
3. 이용 확인 팝업에서 안내 내용 확인 후 **[활성화]** 클릭.
4. 기본값은 꺼짐이며, 활성화 후 **7일간 미사용 시 자동으로 꺼진다** (81_GUIDE_MD 1절 참고).

## 7단계: Codex 사용자용 설정 (Claude Code 대신)

이 프로젝트의 `.mcp.json`은 **Claude Code 전용 포맷**이다. Claude Code는 프로젝트 폴더를 열면 `.mcp.json`을 자동으로 읽지만, **Codex CLI는 이 파일을 인식하지 않는다.** Codex를 쓰려면 아래 과정이 필요하다.

1. **Codex CLI 설치**: [OpenAI Codex CLI 문서](https://developers.openai.com/codex/cli) 안내에 따라 설치 (`npm install -g @openai/codex` 등, 배포 채널은 버전에 따라 바뀔 수 있으니 공식 문서 확인).
2. **Python 설치**: 4단계(Python 설치)는 Codex 사용자도 동일하게 필요하다. `pip install -r 30_MCP_SERVER/requirements.txt`까지 진행.
3. **MCP 서버를 Codex에 등록**: Codex는 프로젝트별이 아니라 `~/.codex/config.toml`(유저 홈 디렉터리)에 전역으로 등록한다. 아래 내용을 추가:
   ```toml
   [mcp_servers.mabinogi-ai-connector]
   command = "python"
   args = ["절대경로/AI_Mabinogi/30_MCP_SERVER/server.py"]
   ```
   - `args`의 경로는 이 프로젝트를 클론한 실제 경로로 바꿔야 한다 (Codex는 `.mcp.json`처럼 프로젝트 상대경로를 자동으로 채워주지 않음).
   - `python`이 PATH에 없다면(예: Microsoft Store 스텁만 잡히는 경우) `50_APP` 앱의 설치 마법사에서 "이 PC용으로 자동 설정" 버튼으로 감지된 실제 `python.exe` 절대경로를 대신 넣어도 된다 (`.mcp.json`용으로 만든 기능이지만 경로 찾는 용도로는 그대로 재사용 가능).
4. **동작 확인**: Codex 실행 후 "내 캐릭터 정보 조회해줘" 같은 요청으로 MCP 툴이 호출되는지 확인.

> `30_MCP_SERVER/server.py`는 표준 MCP(stdio) 서버라 클라이언트를 가리지 않는다 — Claude Code든 Codex든 동일한 서버를 그대로 쓸 수 있고, 차이는 **클라이언트가 서버를 등록하는 설정 파일 위치/포맷**뿐이다.
>
> `50_APP`(마비노비 데스크톱 앱)은 Claude Code/Codex와 무관하게 `MabinogiMobile_CLI.exe`를 직접 호출하므로, 앱만 쓸 거라면 이 단계 자체가 필요 없다.

## 자주 발생할 수 있는 문제

| 증상 | 원인 / 해결 |
|---|---|
| `'node'`/`'npm'`은 내부 또는 외부 명령이 아닙니다 | Node.js 미설치 또는 설치 후 터미널 미재시작 → 터미널 재시작, 그래도 안 되면 재부팅 |
| `'python'`은 내부 또는 외부 명령이 아닙니다 | Python 설치 시 PATH 추가 체크 안 함 → 재설치하며 "Add to PATH" 체크, 또는 `py` 명령으로 대체 시도 |
| Claude Code 사용량 제한(rate limit) 메시지 | 구독/결제 미연결 또는 무료 한도 초과 → 3단계(구독 연결) 확인 |
| MCP 서버가 인식되지 않음 | 프로젝트 루트에서 Claude Code를 열었는지 확인, `.mcp.json` 존재 여부 확인, Claude Code 재시작 |
| 게임에서 AI 커넥터가 응답 없음 | 게임 내 AI 커넥터 옵션이 켜져 있는지, 7일 미사용으로 자동 꺼지지 않았는지 확인 |
